# 📋 Acta de Reunión — EduLogic

> **Instrucciones de uso (borrar esta sección al llenar el acta):**
> 1. Copia este archivo y renómbralo con el formato: `AAAA-MM-DD-tema-corto.md`
>    Ejemplos: `2026-07-14-planeacion-sprint-1.md`, `2026-07-21-daily-semana-2.md`
> 2. Llena todas las secciones. Si alguna no aplica, escribe "N/A" (no la borres).
> 3. El moderador de la reunión es responsable de subir el acta a `docs/actas/` el mismo día.
> 4. Los compromisos deben tener SIEMPRE responsable y fecha — un compromiso sin dueño no existe.
